# 第二层：世界树与海

维度 ID 保持 `sdbf:deep_realm_level_2`。Java 源码位于 SlashBlade-SenDims 工作区，实例配置位于 KubeJS 数据包。

## 当前实现

- 总高度 384，Y=-64..319；海平面 64；深海海底基准 -43，开阔海盆采样 -59..-29；树冠采样最高 Y=314。
- 三个群系：深境二层·树区、深境二层·浅滩区、深境二层·深水区。
- 树根区的基础岛体半径由 65–89 扩大到 112–162，使用明显的伸长、大小不同的海湾/半岛及多尺度岸线扰动。相邻岛体可以合并，形成容纳多株世界树的大岛与狭窄水道。
- 浅滩向深海的过渡由约 20 格拓宽到 88–112 格，并消除陆地与浅滩之间的高度跳变；宽度随位置变化。
- 树干沿高度多次弯曲，具有不规则节瘤、扭转沟槽、根部板状膨大、粗糙表面和老树树洞。
- 粗根、支根、主枝、次枝、细枝沿有相关扰动的曲线生长；子枝从父枝的实际曲线上分出。树根随岛岸逐渐贴近地面，半径包含节瘤和生长纹理变化。
- 树冠半径 `165 -> 289`，约为原来的 1.75 倍；叶簇和枝条伸展同步扩大，冠缘有多尺度起伏，保留天空开口。
- 土壤包括蕴魔草地、灰化土、砂土、缠根泥土；浅滩包含泥巴、茂密海草、睡莲和偶见红树林；深海包含碱晶体、海带丛及海草。
- 蕴门原木主要生成在树洞内壁，填充纹理朝向洞内，外壁仅极少量出现。
- 每个 4×4 树单元组有 50% 概率预留一个 2×2 单元的无树海盆，总体仍约 12.5% 单元。开放海域更集中，给大型水下结构保留自然生成空间。
- 三种旧船、海怪船按水面锚定；沉没之城整组结构按起伏海底支撑高度平移、顶部露出海面；紫晶蟹巢穴贴合岛面。兼容逻辑仅作用于世界树生成器。
- 第二层传送门寻找干燥、安全岛面；维度 ID 与其他维度的配置保持原样。
