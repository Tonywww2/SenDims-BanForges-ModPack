# 难度翻译匹配与分级选择确认

2026-11-02，适用于当前 ApricityUI 1.2.7 难度选择界面。

## 翻译问题与修正

原先中文语言文件只有 N-7～N+10 的名称键，缺少 `kubejs.difficulty.n_11`～`n_18`。N+11～N+18 的描述翻译其实已存在，但界面读取服务端脚本中的空描述、并直接拼接名称，导致这些翻译没有被使用。

现在统一通过 `kubejs.difficulty.n_<level>` 与对应 `.desc` 读取 N-7～N+18 的名称和描述：

- 客户端收到难度数据后，用当前游戏语言解析名称、描述和弹窗文字，再交给 AUI 渲染。
- 服务端聊天前缀、悬停说明、选择成功广播、锁定提示等使用可翻译文本组件，由接收方客户端显示。
- 旧聊天矩阵的名称也保留为可翻译组件，只按原始短标签计算留白。
- 补齐中文名称键，并提供英文回退语言文件，避免其他语言下直接显示翻译键。

数值、颜色分档、方向限制、永久副修正、存档阶段 ID 和网络提交格式均保持原有规则。

## 分级弹窗

按本次提交的目标主难度累加，而非只对跨越的新阈值提示。无改动或已锁定时不会提交；只追加副修正但仍处于高难度时，同样需要相应确认。

| 目标难度 | 弹窗数量 | 顺序 | 输入要求 |
| --- | --- | --- | --- |
| N-7～N+5 | 0 | 原有提交行为 | 无 |
| N+6～N+9 | 1 | 战斗强度 | 无 |
| N+10～N+14 | 2 | 战斗强度 → 战斗时长 | 无 |
| N+15～N+17 | 3 | 战斗强度 → 战斗时长 → 高难度综合提醒 | 第三个框输入 `Yes` |
| N+18 | 4 | 上述三个 → 极限难度提醒 | 第三个框输入 `Yes`，第四个框输入 `Confirmed` |

弹窗文字保存在 `kubejs.difficulty.confirm.*` 语言键：

1. **combat**：该难度会让战斗强度明显提升，对装备和操作水平的要求更高。
2. **duration**：该难度会明显延长战斗时长，请谨慎选择。
3. **high**：该难度会大幅延长战斗时长，并大幅提升战斗强度，对装备和操作水平的要求非常高，同时还可能间接限制一定的流程自由度，请谨慎选择。
4. **extreme**：该难度十分困难，会极大幅度延长战斗时长、提升战斗强度，同时会间接导致流程自由度严重降低。不建议一般玩家选择。

后两个输入框忽略大小写，并容许首尾空格；必须完整匹配单词。每个新框都会清空输入，`Yes` 不能代替下一框的 `Confirmed`。输入不符时确认按钮禁用，点击处理函数也会再次检查。

## 提交与取消

- 只有最后一框确认通过才发送原有 `sdbf_difficulty_menu apply` 命令；保留副修正的原始应用顺序。
- 弹窗开启时冻结本次目标主轴与副修正快照，拦截底下矩阵的选择和缩放，隐藏可能盖到弹窗上的原生物品图标。
- 点击“返回修改”或按 Esc 均取消本轮确认，保留待选内容；再次提交从第一框开始。
- Tab 焦点限制在弹窗中；普通提醒默认聚焦取消按钮，输入提醒聚焦文本框。
- 若待选内容变化则放弃本轮确认，要求重新提交。成功提交设置一次性标记，避免连续点击重复发送；页面卸载时清理确认状态和键盘监听。
- 服务端继续执行原有主轴、方向锁定及副修正合法性校验。此改动是选择界面的防误选交互，没有更改难度计算。

## 验证与限制

运行 `node docs/tools/test_difficulty_confirmation.cjs`：

- 562 项翻译、界面状态和服务端显示检查通过。
- 795 项原有难度回归检查通过。
- 覆盖全部 26 档主难度、中英文名称/描述、四级弹窗顺序、错误与混合大小写输入、逐框取消、空操作、锁定、快照变化、重复点击、底层控件拦截、物品图标恢复，以及页面卸载。
- 直接执行实际 HTML 内的脚本和客户端数据接收回调；DOM、网络连接和文本组件使用离线替身。AUI 表单、焦点、事件等 API 已按安装 JAR 自带文档核对，尚未启动 Minecraft 做实机布局检查。

原回归用例有一处旧随机上界期望：测试将随机数固定为 0，却期望生命值使用 1.15 倍随机上界。已先在修改前脚本复现同样失败，再将该用例修正为实际的 `13000 × 1.8 = 23400`；没有修改游戏的生命值参数。

后续修复了 AUI 输入框清空后未同步光标的问题：切换或关闭弹窗时同时清理光标、选区和撤销历史，另通过 58 项实际 AUI 编辑字节码验证。详见 [AUI 难度确认输入崩溃修复](../development/AUI-难度确认输入崩溃修复-2026-11-02.md)。
