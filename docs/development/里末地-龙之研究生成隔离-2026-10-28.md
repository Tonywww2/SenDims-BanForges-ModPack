# 里末地的龙之研究生成隔离

龙之研究 3.1.2.621 的三个末地生成项原本都通过 `#minecraft:is_end` 添加。整合包将原版末地群系和里末地的五种独立群系都加入了这个通用标签，因此仅有 SenDims 对混沌岛的维度限制，无法阻止原版末地生成龙矿石和彗星。

## 修改

新增 `#sdbf:inside_the_end` 群系标签，仅包含里末地的五种独立群系。覆盖龙之研究的以下 biome modifier，让它们使用该标签：

| 项目 | 地物 ID | 生成阶段 |
| --- | --- | --- |
| 末地龙矿石矿脉 | `draconicevolution:end_draconium_ore` | `underground_ores` |
| 龙矿石彗星 | `draconicevolution:end_comet` | `surface_structures` |
| 混沌岛 | `draconicevolution:chaos_island` | `raw_generation` |

混沌岛覆盖文件必须叫 `chaoos_island.json`，与模组原文件的拼写一致。

保留当前矿石设置：每次放置的 count 为 5，高度 Y=140–220，矿脉 size 为 8，可替换末地石和 `#minecraft:base_stone_end`。保留模组的彗星设置：Y=128–175，rarity filter 为 10000。彗星先放置生成器方块，服务端加载后由其 tick 生成核心和尾部；代码没有限定必须在原版末地。

主世界、下界的其他龙矿石变种不在本次末地生成迁移范围内。通用的 `#minecraft:is_end` 标签保留，用于其他模组的末地兼容。

## 原版末地内容

逐项比较安装环境中的 Minecraft 1.20.1 原始数据，里末地现有五种群系的完整定义均与对应原版群系一致，包含生物、效果及全部自然地物：

| 群系 | 原版地物 |
| --- | --- |
| `sdbf:inside_the_end/the_end` | 黑曜石柱 `minecraft:end_spike` |
| `sdbf:inside_the_end/end_highlands` | 折跃门 `minecraft:end_gateway_return`、紫颂植物 `minecraft:chorus_plant` |
| `sdbf:inside_the_end/small_end_islands` | 小型末地岛 `minecraft:end_island_decorated` |
| `sdbf:inside_the_end/end_midlands` | 与原版一致，无额外群系地物 |
| `sdbf:inside_the_end/end_barrens` | 与原版一致，无额外群系地物 |

原版末地城结构使用 `#minecraft:has_structure/end_city`，整合包已将里末地的高地和平地加入该标签；沿用原版结构及其末地船生成逻辑。这里核对的是原版群系自然地物和世界生成结构，未增加末影龙战斗管理器等仅由原版末地维度运行的机制。

## 验证

- 安装的龙之研究 JAR 中，全部三个以 `#minecraft:is_end` 注入的 biome modifier 均已有同路径覆盖。
- 每个覆盖文件仅更换群系选择器，地物和生成阶段与模组原文件一致。
- 其他已安装模组没有额外注入上述三个龙之研究地物。
- 当前整合包的维度定义中，仅里末地使用这五种独立群系。
- 五种群系完整定义与原版数据一致，末地城群系条件覆盖正确。
- SenDims 现有混沌岛限制的目标维度为 `sdbf:inside_the_end`，龙之研究的混沌岛、彗星开关均已开启。

以上为本地 JAR 字节码、资源和数据包审计，未启动游戏实测新世界。审计结果保存于 `docs/archive/inside-end-worldgen-20261028/audit.json`。

## 更新文件

远程更新时，在整合包根目录添加以下四个文件即可，无需重新构建模组 JAR：

```text
kubejs/data/sdbf/tags/worldgen/biome/inside_the_end.json
kubejs/data/draconicevolution/forge/biome_modifier/chaoos_island.json
kubejs/data/draconicevolution/forge/biome_modifier/end_comet.json
kubejs/data/draconicevolution/forge/biome_modifier/end_draconium_ore.json
```

重启游戏或服务器后，对新生成区块生效。已有区块中的矿石、彗星及混沌岛不会自动删除，也不会向已生成的里末地区块补生成。
