## 范围

流体桶不单独绘制，模型与 PneumaticCraft 等模组相同，使用 Forge 的动态桶模型：

```json
{"parent": "forge:item/bucket", "loader": "forge:fluid_container", "fluid": "kubejs:omni_bio_feed"}
```

## 设计原则

- 16×16，1 像素深色描边，光源在左上，每种材质 4～5 级色阶。
- 每条支线有一种贯穿始终的“在制件”外形，后续工序在同一外形上留下工艺痕迹（附魔光纹、结霜、钻孔、激光槽、镀层等）。装配件换成新的外形，看得出产物升级。
- 名为“XX构件”的物品表示经过 XX 设备加工后的在制件，造型对应该设备的效果：研磨成膏、切成薄片、离心分层、冲压成板等。
- 13 个“原生载体封装”构件，统一画成工艺衬片（纸衬加四角铁铆）上固定的原生实物，例如维瑞迪姆斧头、PCB、照片、药水，表示“消耗原生实物并用衬片封装”。工艺衬片本身也画成同一张衬片。
- 方块贴图可无缝平铺，并做了三层处理：
  - 底层石质的明暗按连续噪声取色，相邻两级色阶的交界处插入两者的中间色作为过渡色，另叠一层细噪声和低频斑驳。
  - 晶体、矿瘤、脉络、孢子等装饰的外沿一圈，向装饰色混合约 38%（裂纹 20%，万用电解构件 22%），形成发光或阴影过渡。
  - 最后按固定随机种子给约 18% 的非装饰像素各压暗或提亮 7%，作为杂色。
  - 万用电解的铜框面板、蜂巢格、菱形晶格等规则图案另按受光方向加了半级明暗：上沿与左沿亮，下沿与右沿暗。
- 流体按各自的工艺单独配色，不再按支线统一颜色。静止动画 16×256（16 帧，每帧 3 刻），流动动画 32×512（16 帧，每帧 2 刻），配套 `.mcmeta` 一并更新。

## 重新生成

绘制代码在 `docs/tools/omni_alloy_textures/`，取代了旧的 `docs/tools/omni_textures/`。每个物品是一段手绘像素模板加材质色阶与工艺细节，方块和流体由可平铺噪声生成。需要 Python 和 Pillow，在整合包根目录运行：

```text
python -X utf8 docs/tools/draw_omni_alloy_textures.py
python -X utf8 docs/tools/validate_omni_alloy_textures.py
```

第一条是完整流程：读取 `omni_alloy.js` 的目录，核对贴图清单与登记一致，写入 `kubejs/assets/kubejs/textures`，刷新物品与方块模型、`docs/kubejs/recipe-research/omni-alloy-implementation.json` 的生成文件清单，并输出放大总览图 `docs/archive/cache/omni_alloy/material-textures-preview.png`。`implement_omni_alloy.py` 重建路线时调用同一套绘制代码。上面保留的 9 张贴图不会被改动。

只想重画贴图、或输出到别处预览时，运行 `python -X utf8 docs/tools/omni_alloy_textures/build_all.py [输出目录]`。修改单个材料时，编辑 `i_*.py`（物品）、`blocks.py`（方块）或 `fluids.py`（流体）中对应的条目；`build.py` 是供其他脚本调用的入口。

### 校验规则调整

`validate_omni_alloy_textures.py` 有三条规则按新贴图调整：

- 方块无缝：原规则要求第 0 行与第 15 行、第 0 列与第 15 列像素完全相同，这会在拼接处形成两像素宽的重复线。现改为比较首尾拼接处的色差与贴图内部最大的相邻行（列）色差，拼接处不得明显更突兀。
- 流体动画：原规则固定 4 帧、每帧 8 刻。现要求宽度仍为 16（静止）或 32（流动）、至少 4 帧、各帧互不相同、`frametime` 为正整数且不插值。
- 流体桶：原规则检查手绘桶贴图。现要求桶模型正是上面的 `forge:fluid_container` 写法、目录中没有 `bucket_texture` 字段，并且不再残留手绘桶贴图。

其余检查不变：原生 16×16、无半透明、物品有透明轮廓、方块不透明、贴图互不重复、模型引用一致、文件在生成清单中。
