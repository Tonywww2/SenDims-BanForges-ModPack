# 麻将成就与强制终止修复（2026-11-18）

目标版本：Minecraft 1.20.1、Riichi Mahjong Forge 0.2.0、HotAI 1.0。生成器见 [mahjong_2026_11_18](../tools/mahjong_2026_11_18/README.md)。

## 一、成就未触发

### 原因

模组共有 51 个役种成就，全部使用 `minecraft:impossible` 条件，只能由 `MahjongYakuAdvancements.awardForWin` 主动授予。牌桌结算时只把 `WinResult.yaku()` 与 `WinResult.yakuman()` 的枚举名交给它。2026-10-24 的补丁已经补上具体役满与六个名称映射，其余 44 个成就都能正常触发。剩下 7 个成就无论怎么胡都不会完成：

| 成就 | 原因 |
| --- | --- |
| 宝牌 `dora`、赤宝牌 `akadora`、里宝牌 `uradora` | 麻将核心只在 `WinResult.doraCount` 里记一个总数，普通役枚举没有这三项，名称列表里永远不会出现 |
| 流局满贯 `nagashi_mangan` | 核心在荒牌流局时只改点数，`RoundEnded` 的胡牌结果为空，`playFinalWinEffects` 直接返回 |
| 国士无双十三面 `kokushi_musou_juusanmen_machi`、四暗刻单骑 `suu_ankou_tanki`、纯正九莲宝灯 `junsei_chuuren_poutou` | 核心的役满枚举没有这三种双倍役满，只会给出国士无双、四暗刻、九莲宝灯 |

带宝牌的胡牌原本只授予手牌中真正成立的役种，宝牌类成就本身从未被授予。

### 修改

- `WinCalculator.calculateBest` 每次返回前，按本次结果的实际牌和宝牌指示牌记录额外成就键，结果、番数、点数完全不变：
  - 非役满的有役胡牌：表宝牌命中（规则把拔北计为宝牌时，拔北也算）→ `dora`；手中有赤五 → `akadora`；里宝牌命中 → `uradora`。核心只在立直时传入里宝牌指示牌，因此里宝牌只在立直和牌时成立。役满不计宝牌，与计分一致。
  - 国士无双且和牌张在手中恰为两张（和牌张组成唯一的对子）→ 十三面。
  - 四暗刻且和牌张在手中恰为两张（单骑听对子）→ 四暗刻单骑。
  - 九莲宝灯且去掉和牌张后正好是 1112345678999 → 纯正九莲宝灯。
- 记录按 `WinResult` 实例保存，最多保留 128 条，只供结算查找。
- `MahjongTableBlockEntity.playFinalWinEffects`：
  - 原结算调用之后，取出该结果的额外成就键，经原 `awardForWin` 授予获胜玩家。
  - 方法开头新增流局检查：没有胡牌结果、牌山已摸完（荒牌流局）、规则允许流局满贯时，对每个满足核心 `isNagashiManganEligible` 的座位，授予在线入座玩家 `nagashi_mangan`。途中流局（九种九牌、四风连打等）不授予。
- 授予沿用原 `grant` 的完成检查，不会重复发放成就奖励。机器人与离线座位不发放。

没有修改役种判定、计分、结算显示、广播、麻将之星或成就数据文件。已经错过的成就不会追溯发放。

## 二、强制终止本局

### 原因

原模组没有中途结束对局的功能：`endGame()` 只在牌桌收到红石上升沿且整场已经结束时调用；对局中扳手右键中央，v3 补丁只提示“对局或结算尚未结束”。对局卡住或有人离开时只能拆桌。

### 修改

牌桌接收红石信号时（九格牌桌任意一格被充能，例如拉杆打开，或按钮按下期间（石按钮约 1 秒）），手持麻将扳手潜行右键牌桌中央即可强制终止当前对局：

- 仅入座玩家或 OP（权限等级 2）可以执行；其他玩家会在动作栏收到提示，对局不受影响。
- 执行时先按原模组换阶段的方式收回已经发到玩家手里的摸牌，再清除结算动画并调用原 `endGame()`，牌桌回到空闲，可重新开局。
- 执行者与在线入座玩家会在聊天栏收到“[麻将] 某某 强制终止了本局。”。本局点数作废。
- 牌桌没有红石信号时保持 v3 行为；“对局或结算尚未结束”的提示末尾加上强制终止的操作说明。
- 红石上升沿在对局中仍然没有作用。结束后拉杆保持打开不会自动开局；需要关再开，或像原来一样潜行右键中央开局。

入口接在 v3 的 `sdbf$openWrenchMenu` 中，方块右键与模型点击两条路径都会经过这里，`MahjongTableBlock` 无需改动。

## 安装

已加入 `SDBF-Update-2026-11-18`。服务端须停止后安装，再完整重启，`/reload` 不加载字节码补丁。安装脚本先把旧的 `hotai/com/riichimahjongforge/mahjongtable/MahjongTableBlockEntity.badiff` 移到 `hotai_backup/`，再放入新类。首次启动后 HotAI 把 `.class` 转为 `.badiff`，属正常现象。联机时只需服务端安装。
