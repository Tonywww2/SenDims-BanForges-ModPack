# Tetra 自定义材料耐久：按阶段递增调整

2026-11-05。修改 `kubejs/server_scripts/tetra/s2_tetras.js`～`s5_tetras.js` 中 100 个材料的 `setDurability`，只上调，不下调；1 阶段与原本已属高耐久的材料（如钻石、绿宝石、凋零合金、2 阶段的下界合金、紫金、烈焰锭、远古金属等）不变。特殊材料（`special_material.js`）与 `kubejs/data/tetra/materials/` 的静态覆盖不在统计范围。

## 取值原则

- 每阶段同时看平均值和中位数，都落在比上阶段高 15%–30%。
- 同一阶段内按材料类型分层：合金、锭、核心等高于普通金属与宝石；石头、粉尘、纤维、布料、果实、蜂蜜类明显偏低（如蜂王浆 220、红石蜂巢网 200、爆裂紫颂果 170、紫菘玻璃 260）。
- 每阶段保留少量顶尖材料作为高耐久上限（3 阶段中子 860、4 阶段补天合金 900、5 阶段泰坦二型复合锭 920）。
- 同一模组的进阶顺序保持一致：Ad Astra 戴斯 300 < 紫金 600 < 耐热金属 660；暮色森林 铁木 290 < 骑士金属 320 < 炽铁 450；深暗之园 扼塞 340 < 御腐 440 < 遗忆 720；Ender IO 震动合金 360 < 末地钢 700；龙之研究 龙锭 580 < 飞龙核心 620 < 神龙核心 800 < 混沌核心 880；植物魔法 魔力钢 380 < 泰拉钢 760。
