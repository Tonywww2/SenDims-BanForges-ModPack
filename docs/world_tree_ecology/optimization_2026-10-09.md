# 深境二层性能优化 · 2026-10-09

## 已安装的优化

维度 ID 保持 `sdbf:deep_realm_level_2`，384 格高度、海平面、世界树形状、树脂概率、植被、珊瑚、结构、战利品配置沿用原值。

1. **横向群系缓存**：每个 biome source 实例独立保存 X/Z 分类；忽略重复的高度采样，目标容量 16,384，溢出时批量淘汰 2,048 项，支持并发。
2. **树木垂直索引**：为每列的木段与树叶建立 16 格高的 section 索引，排除不可能相交的几何；保留原来的精确形状判定和顺序。
3. **树干截面缓存**：树中心、渐细、树瘤和板根粗细的高度项仅计算一次，邻近列共用不可变截面。
4. **填充与高度图**：按保守最高占用高度跳过上部空气；向下填充时同步得到各类高度图，省掉填完后的重复扫描。
5. **空高度图提前返回**：原版 `primeHeightmaps` 收到空集合时立即返回；加载已保存完整高度图的区块时避免无效扫描。非空集合仍执行原版逻辑。

## 一致性验证

- **纯几何**：三个布局参数组合与种子、13,350 列、5,153,100 个高度位置，旧版／新版的地形、方块类别、木头、树叶、最高点完全一致；317,870 个木头位置的填充原木朝向一致；4 线程复测通过。
- **原生群系**：80,000 次查询，覆盖四个高度、负坐标、4 线程与缓存淘汰；与旧版分类一致。
- **原生 NOISE**：64 个实际区块、6,291,456 个方块与 base column 相同；所有现有 WG 高度图逐项等于原版重新扫描结果。
- **原生 FULL 存档**：256 个区块、25,165,824 个方块、393,216 个群系格与旧版逐项比较通过；结构信息、高度图及稳定的方块实体内容一致。比较解码后的方块状态，允许调色板内部顺序不同。
- 空高度图注入通过实际运行验证：空集合调用不读取区块；非空集合在 NOISE 检查中与原版结果一致。
- 发布包只替换通过验证的世界树类与新增 Mixin／映射条目；其余安装包条目逐字节保留。验证与性能探针未进入发布包。

## 配置与后续空间

本轮保留生产 Smooth Boot 的 27 个 main worker。预热结构模板会把首读成本移到进入维度；目前没有证明总等待时间下降，暂不启用。线程数调优需要结合完整客户端载图和帧时间进行独立测量，本轮性能提升来自生成代码和高度图路径。
