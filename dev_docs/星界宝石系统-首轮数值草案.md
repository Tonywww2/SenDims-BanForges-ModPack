## 统一计分

令 e 为修正后三维的加权值：主项 70%，其余各 15%，分别除以 500、200、100。e 可以超过 1。

| 参数 | 首轮配置 | 用途 |
| --- | --- | --- |
| 原生型基础总分 | 1000e | 例如 e=0.4 时自产基础 400 分 |
| 放大、转换型基础总分 | 50e | 保留少量自身基础分，避免同时拥有高产分和高放大 |
| 读取输出的公共效率 | 2e | 表中读取公式的结果乘以 2e，再加入自身基础分 |
| K、K₁、K₂ | 100 | 乘积、差值、加工比例等公式的固定尺度 |
| 按数量连乘的每次倍率 | 1.4 | 种类、角色、空格、超限维度、连片、方阵等 |
| 平滑条件的最高额外奖励 | +50% | 达标后一般为原效率的 1.5 倍 |
| 连续匹配曲线 | exp(−4d) | d 为归一化差距；三维平衡使用最大值减最小值 |
| 多分数基础分 | 等分 | 读分核心自身的弱基础分按其输出类型等分；与读入后的拆分比例独立 |

不同来源必须来自不同格子。没有特别规定的多候选选择，建议自动选择本核心公式产出最高的组合；并列时按格子序号。充能红石 β也采用该规则：比较 B×1＋Δ×1 的输出，再把 B 转敏捷、Δ 转智力。

## 徽章软限制

建议对应分数输入 S 与徽章修正后三维加权 eᵦ分别压缩：

```
C(S) = 0.10 × ln(1 + S / 1000)
η(eᵦ) = sqrt(ln(1 + eᵦ) / ln(1.4))
R = C(S) × η(eᵦ)
```

S 只汇总徽章所在容器中本轮有效填充物的对应分数；不跨容器合并。每名佩戴者只有一枚专属徽章生效。多属性核心建议每项乘 0.65，单属性为 1。S=0 时收益为0，不设50%硬上限。

| 输入分数 S | eᵦ=0.4 的攻击增幅 |
| --- | --- |
| 649 | 约5% |
| 19086 | 约30% |
| 32115 | 约35% |
| 147413 | 约50% |
| 1000000 | 约69.09% |

在相同布局和分数下，eᵦ由0.4升至1，η由1升至约1.435；原先+30%会变为约+43.05%，符合已确认的39%–45%参考提升。此表是曲线计算结果，并非已经验证的毕业布局。

## 属性转换：已启用的首轮系数

攻击、生命、治疗、经验采用最终倍率加成；初始为0的属性须采用固定加值。例如癫火伤害属性为0时，单纯乘其自身数值无法产生效果。

| 输出 | 实际操作 | 单属性 R=35% 时 |
| --- | --- | --- |
| 攻击力 | 最终倍率 +R | 当前攻击力 ×1.35 |
| 拔刀剑伤害系数 | 最终倍率 +R | 当前系数 ×1.35 |
| 癫火伤害 | 固定 +R | 属性 +0.35 |
| 暴击率 | 固定 +R | +35个百分点 |
| 暴击伤害 | 固定 +R | +35个百分点 |
| 盔甲穿透 | 固定 +50R | +17.5点 |
| 盔甲撕裂 | 固定 +R | +35个百分点 |
| 魔法穿透 | 固定 +100R | +35点 |

| 受到治疗倍率 | 最终倍率 +R | 当前倍率 ×1.35 |

固定值属性使用各自系数，均已启用。火焰与寒冰暂以1300攻击参考标定；盔甲穿透以50点、魔法穿透以100点为尺度。暴击、穿透与癫火的实际收益受玩家原属性、敌方防御和技能触发方式影响，这些系数是可调的首轮基准，不代表所有输出都等价于35%最终伤害。多属性徽章在上述结果上再乘0.65。
