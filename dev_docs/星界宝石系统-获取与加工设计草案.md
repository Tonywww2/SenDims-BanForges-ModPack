# 星界宝石系统获取与加工设计草案

版本：第一版草案修订四／三维生成第二版。日期：2026 年 10 月 4 日。

2026-10-05制造配方更新：初／中／高阶加工剂的常规组合锻造产出为2／2／1，压力室产出为3／3／2，原料与加工条件不变；移除普通及机器两条高阶64份大批配方。下文原制造草案及其成本、神门残片兑换比例推算保留作历史记录，当前制造配方以 `13_processing_config.js` 和游戏配方为准。

本稿完善土卫六与深4主线中的宝石开启、初次加工、材料消耗和后续强化。加工剂、强化剂、配方、数据复制、徽章拆出、10次上限及审核通过的文本已接入。2026年10月4日按用户要求重做天然三维生成：改用旧实现的有界抽样思路，恢复整数三维，并恢复影响较小的玩家幸运。下列数值仍可按实机体验调整，旧概率目标保留作比较，不代表已实现的实际概率。星浆作物等待模组新增，任务正文未起草。

核心流程是：在土卫六积累陨铁、小怪掉落及进阶材料，击败神明吞噬者进入深4，取得真正的星浆后制作星界躯体和加工道具。初步探索即可使用中档加工；击败拉塔恩后，以每批消耗神门残片的高档加工持续刷取更好的宝石。

## 开启与进阶流程草案

| 时点 | 玩家行为 | 开放内容 |
| --- | --- | --- |
| 土卫六探索 | 寻找陨铁碎块，击败冰硅甲虫、托林织体蛛等小怪，采集托林与氢泡菌毯 | 准备低档原料，并可提前制作冰晶合金、氮质体膜片、多磷腈辅酶 |
| 击败神明吞噬者 | 获得拟态星浆并进入深4 | 拟态星浆承担进入深4的用途 |
| 深4初步探索 | 用玻璃瓶取得真正的星浆，使用投影框与锻造垫 | 制作星界躯体、空徽章、低档及中档加工道具，开始配置填充物 |
| 深4持续探索 | 扩大星浆储备、收集材料，选择不同宝石和主修饰，调整布局 | 中档成为长期基础加工方式；除杂及定向强化可在此阶段制作 |
| 击败拉塔恩 | 获取神门残片 | 高档加工开放，能够处理龙石、泪宝石，也可提高低、中级宝石的良品率 |
| 长期进阶 | 重复挑战拉塔恩，取得新的原料宝石，建设可再生星浆供应 | 追求更好的三维、适合布局的字母及附加修饰，并强化保留下来的宝石 |

首版采用中档在初步探索后开放。它仍需要土卫六的进阶材料和两种深4工艺，玩家有材料加工过程；不额外增加探索任务门槛。低档依靠较低成本保留用途。

现有星界躯体配方使用拟态星浆，神明吞噬者掉落后即可制作。草案改为真正的星浆，保留拟态星浆的进入维度用途。系统实际生效仍沿用首次进入深4的解锁记录。

本次将原配方中依赖小怪掉落的甲壳、丝囊、合金、膜片与神经腺数量提高到8倍。合金与膜片按现有配方继续制作，通过增加最终配方用量提高战斗消耗，不修改土卫六原有材料配方。辅酶、星浆、耀魂和神门残片数量沿用上一稿；它们的消耗与批次产量仍是草案。

“额外经验成本0”指道具最后这一步，固相星浆现有制作成本仍保留。经验不再叠加成反复刷取时的主要成本，主要消耗来自材料和神门残片。

每批加工剂本体分别消耗1、3、5份原始星浆，已计入晶胚、固相星浆和透星片所用星浆。如果使用新增深4耀魂升阶路线，中阶的1宝珠不额外消耗星浆，高阶的1结晶再消耗3星浆，因此整批合计分别为1、3、8份。利用现有耀魂库存或其他路线时，这部分成本按实际来源计算。

首版采用每个残片产8份高档加工剂。按当前每次4–8个残片计算，一次拉塔恩战斗对应32–64次高档加工，平均48次。机器配方维持相同的残片产出比例；该比例集中配置，可按实机体验调整。

高级宝石必须等拉塔恩之后加工；低、中级宝石始终可以选择高档道具。已经用低档加工过的同一颗宝石不能补付差价升级，需要取得另一颗普通材料宝石。

最高阶耀魂可用于大批生产替代配方：128冰晶合金锭＋128氮质体膜片＋16多磷腈辅酶＋16固相星浆＋8透星片＋64强韧神经腺＋8神门残片＋1耀偏方三八面魂，组合锻造8次，间隔5 tick，额外经验成本0，产64份高阶加工剂。合金和膜片分别拆成两个64件输入格，其余材料各占一格，共10格；不得声明需要单格放128件的配方。与8批常规配方相比，以1个最高阶耀魂替代8结晶；最高阶耀魂的基础制作需要6结晶和1星浆，因此它提供集中精炼后的耀魂节省。神门残片依然每个对应8份加工剂，品质概率完全相同。

## 机器路线草案

Thermal 粉碎机与感应炉沿用现有原料加工，适合自动供应晶粉、合金、膜片和辅酶。现有配方与手工材料数量相同，本稿不把自动化本身描述为现有增产效果。

新增气动压力室的道具批量配方，提供明确的材料节省。已安装气动工艺的压力室支持多种物品输入，适合这组配方；成品是普通加工剂，不含随机宝石数据。

| --- | --- | --- | --- |
| 初阶 | 1陨铁锭＋24冰晶甲壳＋16托林丝囊＋2星浆晶胚＋4耀魂碎片 | 16份 | 1.5 bar |
| 中阶 | 24冰晶合金锭＋16氮质体膜片＋1多磷腈辅酶＋2固相星浆＋2透星片＋2耀魂宝珠 | 16份 | 2.5 bar |
| 高阶 | 24冰晶合金锭＋24氮质体膜片＋3多磷腈辅酶＋3固相星浆＋2透星片＋16强韧神经腺＋2神门残片＋2耀魂结晶 | 16份 | 3.5 bar |

与两批普通路线相比，初阶甲壳从32降到24、陨铁从2降到1；中阶合金从32降到24、辅酶从2降到1；高阶合金与膜片从32降到24，辅酶与固相星浆从4降到3。神经腺、神门残片及耀魂用量维持相同产出成本。综合节省取决于各原料价值，不将不同材料的件数等同为成本。

两条路线产出的同档加工剂完全相同。机器不提高品质概率、不增加主修饰种类、不放宽宝石阶位限制，也不减少神门残片对应的加工次数。玩家可以只用工作台、熔炉和深4工艺完成全部主线产品。

最高阶耀魂的大批压力室替代配方使用64冰晶合金锭＋64氮质体膜片＋12多磷腈辅酶＋12固相星浆＋8透星片＋64强韧神经腺＋8神门残片＋1耀偏方三八面魂，压力3.5 bar，产64份。用户已确认将原稿的96合金与96膜片改为64，以适应已安装压力室的逐格匹配：混合64＋32的同物品需求可能因匹配顺序失败。此配方共8种原料，各项不超过64件；相对手工大批配方，合金、膜片节省50%，辅酶、固相星浆节省25%。神门残片与神经腺用量不变，不提高残片的兑换比例。

## 宝石初次加工与数据保留

按最新确认，宝石操作统一改为物品栏右键叠放。拿起对应加工剂，右键叠放到普通宝石，每次消耗1份加工剂并处理1颗，经验成本0。不额外消耗星浆，相关成本已经包含在加工剂中。耗材制造继续使用组合锻造或机器路线。

三个处理步骤各有明确作用：

| 步骤 | 草案输入与产物 | 数据行为 |
| --- | --- | --- |
| 初次加工 | 普通宝石＋加工剂→已加工宝石 | 完成时首次独立抽取所有属性 |
| 制作填充物 | 纸右键叠放到已加工宝石→宝石填充物，经验成本0 | 复制原型、字母、三维、附加修饰与强化 |
| 镶嵌徽章 | 空徽章右键叠放到已加工宝石→镶嵌徽章，经验成本0 | 将同一宝石数据写入唯一宝石位 |

普通宝石仍使用原物品ID。宝石填充物继续共用 `kubejs:astral_gem_filler`，徽章继续使用 `kubejs:astral_gem_badge`。

加工时同时检查宝石种类、加工剂档位及是否存在新的宝石系统数据。已经加工的宝石、填充物、徽章均不能作为“普通宝石”再次加工；损坏的新格式数据也不得通过再次加工覆盖。

客户端预测不抽取实际结果。服务端确认输入、解锁及产物位置后才生成数据并消耗原料。目标为整叠时，只处理一颗，成品放入玩家背包空格；没有空格则不处理、不消耗。数据变换API的预览回调仍保留，但不作为生存入口。

附加修饰全部清除后，宝石依然处于已加工状态。是否可以再次加工由保留的系统数据与加工记录判断，不能用“附加修饰是否为空”判断。

旧的获取宝石时自动生成等级、三维和旧修饰的逻辑需要退出新流程。只读取新的 `sdbf.astral_gem` 与 `sdbf.astral_badge.gem` 数据，不增加旧格式迁移。

## 品质概率草案

天然三维为大小1–500、纯度1–200、抛光1–100的整数。三个档位使用相同上限，三维使用各自独立的随机数；各条附加修饰的目标三维、加值或百分比类型、正负及数值也分别抽取。强化可以令修正后三维超过天然上限。

主修饰在该种宝石已有的字母中等概率抽取。加工剂档位不把某个字母认定为更好，不提高某个玩法的字母概率。例如有三个主修饰的宝石，各为三分之一。

附加修饰的条数和正负采用下面的首轮参数草案。条数是离散事件，不给整颗宝石设品质区间：先生成1条，再进行4次相互独立的额外词条抽取；每条正负独立判断。

| 参数草案 | 初阶 | 中阶 | 高阶 |
| --- | --- | --- | --- |
| 每次额外词条出现概率 | 25% | 50% | 75% |
| 平均附加修饰条数 | 2条 | 3条 | 4条 |
| 每条为正面修饰的概率 | 55% | 70% | 85% |
| 平均正面修饰条数 | 1.1条 | 2.1条 | 3.4条 |
| 天然三维与正面修饰数值 | 较偏向小值 | 对应原先预期 | 更接近共同上限 |

附加修饰可重复作用于同一维度，不保证平均分布到三维。每条的目标维度按等概率，加值与百分比各50%。用户已确认词条幅度与天然三维采用不同的独立连续分布：正面低／中／高阶分别用u³／u²／u乘以该修饰上限；负面统一用u²乘以负面幅度上限。每条使用新的独立u。以正面大小加值为例，平均分别为＋12.5／＋16.67／＋25，上限均＋50。负面幅度分布不因档位变化；高档通过降低负面出现概率减少负面影响。这不改变仅统计正面条数的Q概率，也避免把天然数值的极端偏低分布直接套到词条幅度。

现有自然修饰校验上限继续保留：加值上限为大小＋50、纯度＋20、抛光＋10；负面分别至−25、−10、−5。百分比为至多＋25%或−12.5%。强化记录独立保存。

### 第二版天然三维生成（当前实装）

用户确认恢复整数三维和玩家幸运，但幸运影响应较小。现采用旧实现的有界对数抽样，再通过平方根得到基础值；统一在长度R＝500的虚拟范围上抽样，避免纯度与抛光因上限较小而更容易接近满值。

初／中／高阶的基础参数p分别为0.95／0.97／0.98。设玩家幸运为L，实际参数为p＋0.001L／(100＋|L|)。幸运10时增加约0.000091，幸运100时增加0.0005，正幸运再高也增加不到0.001；负幸运平缓降低同一参数。幸运只影响天然三维，不改变主修饰、附加修饰条数、正负或幅度。

每项三维独立执行：先令下界a＝p^((R−1)／2)，取独立随机数r，计算u＝a＋(1−a)r，t＝ln(u)／ln(p)，x＝(√(1＋8Rt)−1)／(2(R−1))，再映射为min(该项上限，1＋floor(该项上限×x))。随机输入预先限定在有效范围，因此整数结果不会因把超出上限的大量样本截断而堆积在满值。所有合法整数包括1和天然上限均可获得，不先抽取整颗品质或区间。

集中上限保存为 `global.sdbfAstral.balance.enhancementMaxUses = 10`，位于 `kubejs/startup_scripts/astral_gems/12_balance.js`。道具处理器与Tooltip统一读取这个变量。宝石已用次数保存为 `extensions.enhancement_uses`，新生成时为0；成功使用任一种道具后加1。次数不通过强化条目数量推算，因为除杂没有新增强化条目。

计数属于这颗宝石，转换填充物、镶嵌徽章或拆出宝石都保留，不因换物品形态重置。修改配置上限后，下一次操作按新上限判断；超过调整后上限的宝石保留已有强化，但不能继续使用这四种道具。

失败或没有效果不消耗道具和次数。例如没有负面附加修饰时，不允许提交除杂；额度已满时不允许提交强化。初次加工、制作填充物和镶嵌不计入强化次数。以上提交规则及已批准的错误提示均已接入。

百分比强化可以以后加入，本稿先用固定增量验证材料消耗和提升速度。除杂后若没有任何自然修饰，数据仍合法；API与脚本已允许处理后0条，新生成仍为1–5条。

## 数据与API接入要求

| 项目 | 实装要求 |
| --- | --- |
| 新数据结构 | 沿用schema 1及现有三维、附加修饰、强化字段，不读旧格式 |
| 加工记录 | 在 `extensions` 保存已加工标记、耗材档位和概率配置版本；保留后不因除杂或转换丢失 |
| 强化次数 | 读取 `A.balance.enhancementMaxUses`，统一保存 `extensions.enhancement_uses`；四种道具共享，完整转移时保留 |
| 动态生成 | 物品注册中登记 `meonother`，服务端叠放提交时才生成；原数据变换回调保留 |
| 变量输入 | 叠放处理检查真实物品种类、对应阶位与是否已有新系统数据；原谓词保留 |
| 填充物与徽章 | 使用 `GemPayloadTransfer` 或完整栈复制保留全部数据；共用物品ID按各自NBT动态计算 |
| 除杂空修饰 | 已调整 `GemPayload` 与脚本校验，允许除杂后0条；仍限制新生成1–5条 |
| 拆卸 | 用已有物品数据读写能力还原 `source_item` 对应已加工宝石，保持完整数据，校验返还位置 |
| 原料消耗 | 每次恰好消耗1宝石与1加工剂，失败时不消耗；产物与消耗同次提交 |
| 无限预览重抽 | 预览不给实际随机数；取消不生成，不把显示预览当已完成加工 |
| 删除配方 | 所有需要移除的原配方ID统一放入 `remove.js` |
| 描述实装 | 仅接入已按实际示例明确批准的描述文本；新模板或改写重新提交提问 |

当前API已提供动态工艺与完整NBT复制，单颗加工不需要再扩展一套分数API。本轮已修改 `GemPayload` 的构造与解码，允许0–5条自然修饰，同时拒绝缺失或元素类型不正确的词条列表；新生成依然由脚本限制为1–5条。`ForgingPadMenu` 已补齐提交失败时显示回调原因的行为。已用实际模组及Minecraft NBT验证零词条的编码、解码、强化和计数保留，并重新构建安装。若后续需要一次处理整叠宝石，可另提批量加工API：每颗独立生成、消耗等量道具、支持多个不同NBT产物，并处理背包剩余空间；首版单颗流程不依赖该扩展。

数值转换继续沿用已启用的84个主修饰和13种属性配置。目标仍为约5%起步、约35%常规进阶、进一步刷取可接近或超过50%；不设50%硬上限。固定值属性继续按各自换算系数处理，本稿不重新定义它们的伤害等价关系。
