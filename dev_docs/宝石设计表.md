# 宝石设计表

本表保存当前 34 种宝石、84 个主修饰的设计，供逐项检查。84 项机制已于 2026-10-02 全部确认；字母命名已统一为 α、β、γ、δ。数值参数仍待单独批准。

所有宝石填充物共用一个物品类、一个物品 ID。加工时将源宝石种类、字母主修饰、天然三维和附加修饰写入填充物 NBT，按每个物品栈的数据分别结算。“宝石种类＋字母”才是完整核心身份，不同种类的 α不表示相同玩法。

## 阅读说明

- 原生型自产分数；放大型放大读取的分数；转换型改变读取分数的类型。读分核心保留较弱的自身基础分。
- 默认空间为四向相邻，特殊范围在规则中说明。来源应为开放且生效的宝石填充物；物理空格与失效但有物品的格子不同。
- 每颗只修改自己的结果，使用来源的独立副本。多个接收者可以分别读取同一来源的完整结果。
- 三维天然范围为大小 1–500、纯度 1–200、抛光 1–100；修正后可超过天然上限，最低为1。
- “主三维”列按“填充物／徽章”排列。大＝大小，纯＝纯度，抛＝抛光；主项权重70%，其余两项各15%。
- B是本颗基础总分，F是本轮最终六分数之和，Δ＝max(F−B,0)，加工占比 g＝Δ/F；F为0时g取0。
- K代表核心固定尺度参数。倍率、K、阈值、分配比例、曲线和指数极限尚待统一校准。
- 多属性徽章降低单项系数。专属徽章有一个宝石位，每名玩家只有一枚产生效果。
- 表中普通读取对象按下方来源约定选择，需要不同邻格的输入必须来自不同格子。

## 读取来源约定

普通读取的来源为原生型，按需要的正分数类型选择。已确认的魔力钻石、龙石、穹玉晶石、紫晶石、砷铅铁矿石、充能红石的读分核心，还允许下列 P9 加工名单。魔力钻石 γ额外允许魔力钻石 β。

福鲁伊克斯水晶 β、γ允许原生型及 P9，加工名单排除福鲁伊克斯水晶 β、γ自身，避免互相读取。其余19种的普通读取默认只允许原生型，额外加工来源按表中逐项说明。

P9固定名单：

- 粗制绿宝石 β，`tetra:pristine_emerald#beta`。
- 粗制青金石 β，`tetra:pristine_lapis#beta`。
- 粗制钻石 β，`tetra:pristine_diamond#beta`。
- 粗制紫水晶 β，`tetra:pristine_amethyst#beta`。
- 海晶砂粒 β，`minecraft:prismarine_crystals#beta`。
- 海晶砂粒 γ，`minecraft:prismarine_crystals#gamma`。
- 充能赛特斯石英水晶 β，`ae2:charged_certus_quartz_crystal#beta`。
- 充能赛特斯石英水晶 γ，`ae2:charged_certus_quartz_crystal#gamma`。
- 福鲁伊克斯水晶 α，`ae2:fluix_crystal#alpha`。
- 福鲁伊克斯水晶 β，`ae2:fluix_crystal#beta`。
- 福鲁伊克斯水晶 γ，`ae2:fluix_crystal#gamma`。
- 红宝石 β，`thermal:ruby#beta`。
- 红宝石 γ，`thermal:ruby#gamma`。

基础总分B和位置、种类、角色等元数据可以在来源最终分数尚未计算时读取。它们不产生最终分数的读取依赖；来源筛选仍遵守对应规则。

泪宝石 α、γ、δ读取其他宝石的加工结果，排除全部泪宝石主修饰。泪宝石 β使用固定混合分来源名单：

- 福鲁伊克斯水晶 α
- 氟盐 α
- 龙石 β
- 海晶砂粒 γ
- 氟石 β
- 朱砂 β
- 氟石 γ
- 蓝宝石 γ
- 豆腐宝石 β

泪宝石 γ所需的“不同主修饰规则”按宝石种类＋字母比较。例如，红宝石 β与蓝宝石 β属于不同规则。加工来源名单不会随着新增加工核心自动扩大。
